# WebtoApp v0.5 广告过滤

## 用户界面

生成器新增一个默认开启的选项：

- `启用广告过滤（推荐）`

取消勾选后，生成的 APK 不创建广告过滤引擎，也不下载规则。

## 默认组合

- EasyList
- EasyList China
- AdGuard Mobile Ads
- CJX Annoyance List（仅解析兼容的标准规则）
- WebtoApp 自有精简离线规则

## 处理能力

- WebView 子资源请求过滤；
- ABP 域名锚点、URL 模式、例外规则；
- 资源类型、第三方和 domain 限定；
- 标准 `##` 页面元素隐藏和 `#@#` 例外；
- `generichide` / `elemhide` 兼容例外；
- 非用户触发的广告域名跳转拦截；
- 规则按来源分别缓存，三天检查一次更新；
- 更新失败、解析失败时放行并继续使用旧规则。

## 性能设计

- 网络请求只读取不可变规则快照；
- 域名规则按后缀索引；
- URL 规则按关键字索引；
- 页面隐藏规则在后台线程整理并按域名缓存；
- 不在 WebView 滚动或状态栏动画过程中修改页面尺寸。

## 不支持

- scriptlet / `+js(...)`；
- HTML filtering；
- redirect/rewrite/CSP/response transformation；
- DRM、M3U8/DASH 流媒体广告；
- 与正文由同一接口返回且无法区分的原生广告；
- 完整浏览器扩展级语法。
