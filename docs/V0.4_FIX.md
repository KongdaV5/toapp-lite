# v0.4 changes

- Respect Android status/navigation-bar safe areas instead of drawing webpage controls underneath them.
- Improve image and general file upload through the Android system document picker, including multiple selection and MIME filtering.
- Allow selected `content://` URIs while keeping direct local-file access disabled.
- Remove generic WebView markers from the user agent for better website compatibility.
- Rename the builder and downloadable APK artifact to `WebtoApp`.
